# Lawson Morning for Omarchy

A light-mode winter-morning Omarchy theme inspired by a quiet Lawson storefront
beneath Mount Fuji. Frost-white surfaces, dark slate text, Lawson blue focus
states, muted ice-blue layers, and restrained dawn-peach highlights create a
bright developer workspace without sacrificing terminal readability.

![Lawson Morning theme preview](preview.png)

## Highlights

- Native Omarchy light mode through `mode = "light"`
- Dark text and syntax colors checked against the frost background at 4.5:1 or
  better contrast
- Matching generated colors for terminals, editors, browsers, Hyprland, and the
  Omarchy shell
- Lawson blue and winter-sunrise Hyprland border gradient
- Calm Mount Fuji winter-morning wallpaper
- Matching Yaru blue icons

## Install

Install directly from the public Git repository:

```bash
omarchy theme install https://github.com/phuclh/omarchy-lawson-morning-theme.git
```

You can also paste the repository URL into **Install > Style > Theme** from the
Omarchy menu.

## Terminal transparency

The author's local edition uses `0.94` background opacity in Alacritty, Foot,
Ghostty, and Kitty. Omarchy intentionally discards terminal configuration files
from remotely installed themes and safely regenerates them from `colors.toml`,
so downloaded copies use the user's normal terminal-opacity setting.
